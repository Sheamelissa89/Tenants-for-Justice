# Tenants for Justice

Tenants for Justice is a mobile-first web application designed to help tenants understand their rights, document housing problems, organize evidence, and build a clear record of their interactions with landlords and property-management companies.

## Project Purpose

Tenant disputes can involve scattered photographs, maintenance requests, text messages, notices, inspection reports, and legal information. Tenants for Justice will bring those materials together in one organized and accessible place.

## Planned Features

- Secure user accounts
- Tenant case dashboard
- Incident and communication timeline
- Repair-request tracking
- Evidence and document uploads
- Letter and notice organization
- Case-summary generation
- Tenant-rights information
- Sacramento and California housing resources
- Emergency-help resources
- Mobile, tablet, and desktop support

## Primary User Journey

1. Create an account.
2. Start a tenant case.
3. Record incidents and communications by date.
4. Upload supporting evidence.
5. Track repair requests and management responses.
6. Review an organized case timeline.
7. Generate a case summary for personal records or review by an attorney.
